# 8. Figures that disagree across sources

HISD's own documents, and HISD's figures against TEA's and the bond market's, disagree with each other on several points. None of these are resolved in this edition; they are listed here rather than silently picking one. See [the audit summary](audit-summary.md) for which of these were investigated further and which remain open.

| Item | Values found | Notes |
|---|---|---|
| FY2025 recapture paid | $49.1M (TEA Summary of Finances, Final); $56.9M (audited ACFR and TEA's PEIMS actuals); $44.5M (HISD's own final amended budget); approximately $65M (a bond official statement); $55.5M (a Texas Tribune news report) | Likely a mix of accrual-versus-cash timing and multi-year settle-up adjustments; unreconciled in any HISD document |
| FY2024 recapture paid | $0 (ACFR and PEIMS) versus $326.5M budgeted in HISD's original FY2024 budget | The ACFR's own footnote explaining the $0 is not in the document's machine-readable text layer |
| Tax year 2025 tax rate | $0.8783, including "disaster pennies" added in October 2025 (HISD's own tax-information page) versus $0.8489 (a May 2026 bond official statement) | About $68 million a year of tax levy turns on which figure is correct |
| FY2025 tax rate, within the ACFR itself | 0.7116 / 0.8783 in the statistical summary table versus 0.7016 / 0.8683 in the notes and levy table of the same report | The statistical table row appears to have been populated with the following year's rate by mistake |
| ACFR's own "cost per pupil" historical series | Found to be computed inconsistently: FY2020-FY2022 figures include bond-refunding escrow payments that should have been excluded as non-operating; FY2023 is overstated by about $107M on a recomputed basis | See `notes/acfr.md` for the recomputed, consistent series |
| July 2025 maintenance-tax note issuance | $20.555M (an ACFR subsequent-event note) versus $114.39M (the actual bond market official statement for that issuance) | The ACFR note's text appears to have been carried over from an earlier, smaller issuance |
| FY2025 TIRZ revenue received by HISD | $54.5M (audited ACFR) versus approximately $38M (a bond official statement) | |
| State tax rate cited in HISD's own budget transmittal letters | $1.035 / $1.045 | The budget documents' own detailed tables elsewhere say $0.8683 / $0.8783 |
| FY2026 state Foundation School Program aid, within HISD's own budget book | $110.5M in the narrative text versus $238.2M in the accompanying revenue table | |
| FY2025 budget's stated "Average Daily Attendance" | 179,592 | That figure is actually HISD's enrollment count; TEA's certified refined average daily attendance for the year was 156,871 |
| FY2025 ACFR, as posted on HISD's own website | About 95 of 200 pages are scanned images with no machine-readable text (requiring OCR to read); the first page of the Management's Discussion and Analysis section appears to be missing; the FY2023 report is served under a filename labeled "FY24" | |
