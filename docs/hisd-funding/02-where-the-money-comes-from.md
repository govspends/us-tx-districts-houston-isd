# 2. Where the money comes from

## All governmental funds, audited

| Source | FY2023 | FY2024 | FY2025 |
|---|---:|---:|---:|
| Local (mostly property tax) | $2,319.4M | $2,021.1M | $2,046.4M |
| State | $232.8M | $384.2M | $345.0M |
| — of which TRS pension "on-behalf" (non-cash, offset by an equal expense) | $81.9M | $109.5M | $113.7M |
| Federal | $816.3M | $779.8M | $401.4M |
| **Total** | **$3,368.6M** | **$3,185.2M** | **$2,792.7M** |
| Share local / state / federal | 69 / 7 / 24 % | 63 / 12 / 24 % | 73 / 12 / 14 % |
| Per enrolled student | $17,736 | $17,301 | $15,803 |

<p class="caption">Source: HISD's audited Annual Comprehensive Financial Reports, FY2023-FY2025.</p>

Property tax revenue fell by about $300 million in FY2024. The cause was state-ordered tax-rate compression (HISD's maintenance-and-operations rate fell from $0.8705 to $0.7016 per $100 of value) and the homestead exemption rising from $40,000 to $100,000 — both from 2023 state property-tax relief legislation.

| Mix (local / state / federal) | 87 / 12 / 1 % | 79 / 20 / 1 % | 81 / 18 / 1 % |

A commonly repeated "74% local / 14% state / 12% federal" split is HISD's **all-funds** figure, which includes about $177 million of federal grants that flow through a separate fund. On a General Fund basis — the money that actually pays for day-to-day instruction — federal money is only about 1%.

HISD's total operating revenue per student is exactly the state average. Local plus state alone is $10,392 per enrolled student. HISD is a property-wealthy district by Texas's school-finance standards, so the state covers only about 10% of its operating revenue — against 45% statewide for an average district. The mechanics of why are in [Section 4](04-state-funding-per-student.md).
