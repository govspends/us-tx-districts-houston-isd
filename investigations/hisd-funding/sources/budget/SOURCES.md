# HISD budget sources (adopted budgets FY2024-25 to FY2026-27)

Retrieved 2026-10-06 (FY27 notice and analysis finished 2026-10-07). All PRIMARY items are HISD's own documents, linked from https://www.houstonisd.org/our-district/budget-financial-planning (a Finalsite page; its post pop-ups were fetched through `/fs/elements/<id>?is_popup=true&post_id=<id>&show_post=true`). Each `/fs/resource-manager/view/<uuid>` link redirects to the `resources.finalsite.net` URL shown below.

Each PDF has a sibling `.txt` from `pdftotext -layout`. Page numbers in `notes/budget.md` are **PDF page numbers**. The printed page numbers differ: in the FY25 book, printed page = PDF − 5. In the FY26 book the offset is −6 to −9.
